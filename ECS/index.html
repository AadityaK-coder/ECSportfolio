Tank Game

  • Game Design and Objects: This Tank Game is built using custom classes like Tank, Obstacle, and PowerUp to create behavior for the different objects in the game. All the classes use constructors with variables like coordinates, speed, and health.
  • User Interaction and How to Play: You can use the W, A, S, and D keys to move the tank and click the mouse to fire projectiles at obstacles (cookies). The obstacles can also damage your health. The game tracks your resources through using variables like laserCount and turretCount.
  • Survival and Upgrades: The main goal is to survive as long as possible by avoiding obstacles that damage your health. You can improve your chances by collecting PowerUps that are randomly generated using a Timer. There is a bar on the top that displays your score, health, and ammo.
